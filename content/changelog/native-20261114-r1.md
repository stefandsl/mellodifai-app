# Native runtime without Docker

Replaced the Docker stack with a supervised native runtime on Windows, including a native gateway, backup verification, and crash-tested recovery.

## What changed

- Built the native gateway replacing Kong and moved live feed, job progress, and timeline updates to a shared change-cursor poller.
- Supervised native PostgreSQL, Auth, PostgREST, Storage, web, and worker processes with per-stack hop secrets, redacted rotating logs, and disk-space guards.
- Added portable backup verification, transactional legacy data import, schema rollback markers, and OS leases for serialized operations.
- Verified native PostgreSQL recovery across repeated hard kills under write load in Windows CI.
