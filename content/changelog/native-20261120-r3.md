# Native Windows desktop app, cover candidates, and lyric jury checks

The Windows desktop installer now runs on the native runtime without Docker, renders produce selectable cover candidates, and lyric evaluation checks language, script, and originality.

## What changed

- Shipped the per-user Windows desktop installer running on the native runtime inside its own app window, with isolated caches, update backup retention, and a single-start lock.
- Generated three cover candidates from each render's frames and let owners pick one in Pubblica, covered by the approval hash.
- Expanded the lyric jury with brief alignment, paraphrase, script, and chorus length checks, and redacted reference lyric passages from returned issues.
- Improved visualizer legibility by keeping titles clear of the lower caption band and tightening contrast on editorial and player-card looks.
