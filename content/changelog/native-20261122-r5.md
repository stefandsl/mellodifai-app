# Public site shell, home page, and open-source release

The repository moved to an open-source MIT layout and shipped the first public website pages built on the mesh theme.

## What changed

- Added the MIT license, removed private paths and internal notes from the public tree, and prepared the repository for open-source contributors.
- Added the mesh theme and built the public site shell (fixed glass header, mobile menu, and footer) together with the home page.
- Directed signed-in visitors from `/` straight to the studio while showing the public home page to visitors.
- Added automated layout, clean-room, token, and accessibility checks across Chromium, Firefox, and WebKit in CI.
